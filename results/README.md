# Results

The workbooks in this directory are the supplied analysis outputs.

- `HPA/Analisis_Redes_Splicing_Tejidos_HPA.xlsx`: tissue-expression network results.
- `HPO/Analisis_Redes_Splicing_Enfermedades.xlsx`: phenotype/disease network results.
- `HPO/Base_Genes_Mapeados.xlsx`: mapping of the analysed genes to identifiers used in the HPO workflow.

The workbooks are retained as outputs rather than recomputed summary tables, so the repository keeps a direct link between the supplied analysis and its published tabular results.
