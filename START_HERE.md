# Start here

If you are reviewing this repository for the first time, follow this order:

1. **[README](README.md)** — technical overview and key quantitative findings.
2. **[Results gallery](docs/portfolio/RESULTS_GALLERY.md)** — main visual outputs.
3. **[Methods](docs/portfolio/METHODS.md)** — compact technical workflow.
4. **[Results by analysis](docs/portfolio/RESULTS_BY_ANALYSIS.md)** — numerical results by analytical branch.
5. **[Reproducibility](docs/portfolio/REPRODUCIBILITY.md)** — exactly what is reproduced by the supplied R workflow and what originated from external platforms.
6. **[`scripts/analysis/network_analysis.R`](scripts/analysis/network_analysis.R)** — main R analysis workflow.
7. **[`docs/tfm/TFM.pdf`](docs/tfm/TFM.pdf)** — complete Master's Thesis.

## For a technical recruiter

**README → Results Gallery → Results Summary → `network_analysis.R` → TFM**

The repository is intentionally organised so that the scientific result can be evaluated before reading implementation details.

## For a researcher / bioinformatician

**Project Overview → Reproducibility → Data → R workflow → Results → TFM**

The repository preserves supplied inputs, result workbooks, figures and academic documentation while distinguishing source-derived outputs from R-generated analyses.
