# Results by analysis branch

## PPI topology

The STRING network contains **86 connected genes and 1,832 edges**. The reported mean interaction score is **0.784**, with **96 expected interactions** for a random set of the same size and a PPI-enrichment result of **p < 1 × 10⁻¹⁶**.

The topology separates direct connectivity from intermediary position. `SF3A2` has the highest degree (**69**), whereas `SRSF1` has the highest betweenness (**268.84**).

## Functional enrichment

The global enrichment is dominated by RNA-splicing and RNA-processing terms. Reported leading biological-process terms include RNA splicing, mRNA splicing via the spliceosome, mRNA processing and RNA processing.

## HPA

The global tissue network contains **76 genes, 346 tissues and 12,527 bipartite connections**. The highest reported gene degrees are `HNRNPK` and `HNRNPM` (305 each), followed by `SRSF3` (298), `HNRNPA2B1` (285), `HNRNPU` (284) and `SNRNP70` (283).

## HPO

The global phenotype network contains **27 mapped genes, 516 phenotypes and 836 bipartite connections**. The global Jaccard projection produced **14 Louvain communities**.

The highest reported gene degrees are `SF3B4` (82), `HNRNPK` (70), `HNRNPH1` (59), `SF3B2` (54) and `CRNKL1` (53).

## Clinical interpretation

The thesis combines network centrality with evidence from OMIM, ClinVar and PubMed for the 15-gene reference subset. The resulting interpretation distinguishes documented disease associations from cancer-related or indirect functional evidence and does not treat network centrality as proof of causality.
